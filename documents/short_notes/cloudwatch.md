# Amazon CloudWatch

> @sticky_notes

- **Use for:** operational logs, metrics, alarms and Logs Insights queries.
- **Integration:** inspect API Gateway access logs and Lambda runtime logs in
  the configured region; use request IDs to correlate them.
- **Remember:** set log retention, alarm on important error/latency metrics,
  and exclude secrets and tokens from logs.
- **Project guide:** [CloudWatch operations](../aws/operations/README.md).
- **AWS docs:** [CloudWatch Logs](https://docs.aws.amazon.com/AmazonCloudWatch/latest/logs/WhatIsCloudWatchLogs.html)
  · [Logs Insights](https://docs.aws.amazon.com/AmazonCloudWatch/latest/logs/AnalyzingLogData.html)
