# Amazon S3

> @sticky_notes

- **Use for:** object/file storage. This project currently serves its background
  image from Amplify Hosting, not S3.
- **Integration:** keep Block Public Access enabled; use a backend or scoped
  temporary credentials for authorized uploads/downloads.
- **Remember:** CORS is not authorization. For private static content, use
  CloudFront with Origin Access Control and a private bucket.
- **Project guide:** [S3 setup](../aws/s3/README.md).
- **AWS docs:** [S3 security best practices](https://docs.aws.amazon.com/AmazonS3/latest/userguide/security-best-practices.html)
